# ورقتي | Waraqati Studio

> **ورقتك، على طريقتك.**  
> Arrange. Create. Print.

ورقتي مشروع ويب يهدف إلى أن يكون استوديو متكاملًا لترتيب الصور وتجهيزها للطباعة، بدءًا من ملصقات واتساب وصولًا إلى تخطيطات الصور المتعددة ومعالجة الصور دفعة واحدة.

## الرؤية

بناء تجربة تصميم احترافية وجذابة بصريًا، تكون الواجهة فيها أولوية أساسية، مع أدوات واضحة ودقيقة وسهلة الاستخدام على الهاتف والحاسوب.

## ما نخطط لبنائه

- **Sticker Studio:** ترتيب الملصقات والصور في شبكات قابلة للتخصيص.
- **Paper Layout Studio:** تخطيطات جاهزة لصورة واحدة أو صورتين أو ثلاث صور في الورقة، إضافة إلى الشبكات والتخطيطات المخصصة.
- **Photo Studio:** إعداد الصور الشخصية وشبكات الصور وأوراق المعاينة.
- **Batch Lab:** تحويل الصور وضغطها وتغيير أبعادها وإعادة تسميتها ومعالجتها دفعة واحدة.
- **محرك تخطيط وطباعة:** حسابات دقيقة للأبعاد، والصفحات، والمسافات، والقص والاحتواء.
- **تصدير:** PDF وصيغ صور مناسبة، مع معاينة قبل التصدير.
- **مشاريع محلية:** حفظ إعدادات المشاريع والقوالب على الجهاز.
- **تجربة Offline-first:** تنفيذ المعالجة محليًا قدر الإمكان، مع دعم التثبيت كتطبيق ويب عند اكتمال متطلباته.

## الهوية والتقنيات

- الاسم: **ورقتي | Waraqati Studio**
- المستودع: `majd7772233-a11y/waraqati`
- الاتجاه البصري: هوية ليلية عميقة، ولمسات بنفسجية ونعناعية، وGlassmorphism متعدد الطبقات، ومساحة معاينة تشبه الاستوديو.
- التقنية: React 18 وTypeScript وVite 6.
- الاستضافة المستهدفة: GitHub Pages إن ظلت مناسبة لبنية المشروع.

## مبادئ أساسية

1. **جودة الواجهة أولوية رئيسية:** لا نعتمد واجهة افتراضية أو بسيطة لمجرد إنجاز الوظيفة.
2. **الدقة قبل المظهر:** يجب أن تطابق معاينة الطباعة ومخرجاتها المقاسات والتخطيطات المحددة.
3. **الهاتف جهاز أساسي:** لا تُصغّر واجهة الحاسوب فقط؛ صمّم تجربة هاتف حقيقية.
4. **الخصوصية:** تُعالج الصور محليًا قدر الإمكان، ولا تُرفع إلى خادم دون حاجة واضحة وموافقة المستخدم.
5. **الأداء:** لا تُحمّل مؤثرات WebGL ثقيلة على الهاتف ما لم تبرر قيمتها بوضوح.
6. **العمل التدريجي المنظم:** تُنفذ المراحل وفق `ROADMAP.md` وتُحدّث الوثائق مع تقدم المشروع.
7. **لا تجاهل صامتًا:** وضّح الملفات غير المدعومة والأخطاء وأسبابها للمستخدم.

## بنية المشروع الحالية

- `src/App.tsx`: الصفحة الرئيسية ومكتبة الصور المحلية، والاستيراد والبحث والترتيب والتحديد والحذف وربط استوديو التخطيط.
- `src/imageLibrary.ts`: التحقق من امتدادات الصور وقراءة أرشيف ZIP محليًا (Stored/Deflate).
- `src/paperLayout.ts`: محرك تخطيط موحد لحساب مقاسات الورق والهوامش والوحدات والمناطق والشبكات وقص/احتواء الصور وتوزيع الصفحات.
- `src/exporter.ts`: تصدير محلي متعدد الصفحات إلى PDF، وتصدير الصفحة الحالية إلى PNG/JPEG، مع خيارات DPI والجودة والخلفية ومؤشرات تقدم وحدود لحجم المعالجة.
- `src/PaperLayoutStudio.tsx`: استوديو تحرير تفاعلي لاختيار الصور والقوالب، وتخصيص الورق والشبكات والمناطق، وترتيب الصور، ومعاينة الصفحات، والتكبير والتحريك بالسحب، والتراجع/الإعادة، والحفظ المحلي وتصدير إعدادات JSON، وواجهة تصدير PDF/PNG/JPEG.
- `src/i18n.ts`: قاموسا العربية والإنجليزية واتجاه النص ورسائل مكتبة الصور.
- `src/styles.css`: نظام التصميم الزجاجي المتجاوب ومكونات مكتبة الصور واستوديو التخطيط ومساحة التحرير ولوحات الهاتف.
- `vite.config.ts` وملفات TypeScript: إعدادات التطوير والبناء والفحص.
- `.github/workflows/ci.yml`: فحوصات CI.

## الحالة الحالية

- **المرحلة الأولى مكتملة** بعد نجاح CI run 38582795265 في التثبيت وفحص TypeScript والاختبارات والبناء والتحقق من `dist/index.html`.
- **المرحلة الثانية قيد التحقق:** طُبّق نظام بصري متجاوب، وما زال التحقق النهائي مؤجلًا.
- **المرحلة الثالثة — التنفيذ البرمجي:** أضيف استيراد الصور والمجلدات وZIP، ومعاينات وأبعاد الصور، والبحث والترتيب والتحديد والحذف وتقارير الاستيراد؛ التحقق النهائي والاختبارات مؤجلان إلى نهاية التطوير بناءً على توجيه المستخدم.
- مكتبة الصور مؤقتة في الذاكرة ولا تحفظ الملفات بعد تحديث الصفحة. أُضيف محرك تخطيط حسابي مشترك في `src/paperLayout.ts` وربط به استوديو التخطيط في `src/PaperLayoutStudio.tsx`.
- المرحلة الخامسة نُفذت برمجيًا: قوالب لصورة واحدة أو صورتين أو ثلاث صور، وشبكات ملصقات بعدد صفوف/أعمدة أو مقاس ملصق، وتكرار صورة واحدة، ومناطق مخصصة، وقص/احتواء، ومعاينة SVG متعددة الصفحات، وترتيب الصور المختارة. الاختبارات والتحقق النهائي مؤجلان لنهاية التطوير؛ لا تدّعِ نجاحهما قبل تشغيلهما.
- لم يُعتمد Plasma UI في التطبيق: المكتبة `@cruxgarden/plasma-ui` مرخصة MIT لكنها تعتمد WebGL2، وتوضح وثائقها أن الأداء ثقيل نسبيًا على الهواتف. لذلك اختير Glassmorphism عبر CSS كخيار افتراضي أخف وأكثر ملاءمة للهاتف، مع إبقاء قرار Plasma قابلًا لإعادة التقييم بعد اختبار أداء فعلي.
- لا تُعد المرحلة الثانية مكتملة قبل نجاح CI والتحقق من الأداء والاستجابة بصريًا على شاشات فعلية أو محاكاة مناسبة.
- المرحلة السادسة نُفذت برمجيًا: شريط تحرير باسم المشروع والتراجع/الإعادة واختصارات لوحة المفاتيح، تكبير المعاينة وتحريكها بالسحب، حفظ مسودة إعدادات المشروع محليًا، وتصدير ملف إعدادات JSON، ولوحات قابلة للتبديل على الهاتف.
- المرحلة السابعة نُفذت برمجيًا ولم تُتحقق نهائيًا: تصدير PDF متعدد الصفحات وPNG/JPEG للصفحة الحالية، خيارات 72/150/300 DPI وجودة JPEG وخلفية PNG بيضاء/شفافة، مؤشر تقدم ومعالجة أخطاء وحدود لحجم المعالجة. PDF يستخدم خلفية بيضاء؛ اختبارات فتح الملفات ودقة المقاسات ومواضع الصور واستهلاك الذاكرة مؤجلة لنهاية التطوير. حفظ المشاريع وإعادة فتحها بشكل كامل يبقى ضمن المرحلة التاسعة.



## المرحلة الثامنة — Photo Studio وBatch Lab

- **Photo Studio** (`src/PhotoStudio.tsx`): إنشاء أوراق Contact Sheet متعددة الصفحات بصيغ PNG، مقاسات 4×6 و5×7 وA4 ومقاسات مخصصة، ضبط الصفوف والأعمدة والهوامش والمسافات والدقة، وإضافة عنوان أو أسماء أو أرقام للصور. تجاوز عدد الصور للخانات ينشئ صفحات إضافية.
- **Batch Lab** (`src/BatchLab.tsx` و`src/imageProcessing.ts`): تحويل PNG/JPEG/WebP، تصغير الأبعاد مع الحفاظ على النسبة، ضبط الجودة، تدوير الصور، قص الحواف الشفافة، وقوالب إعادة التسمية. تعرض المعاينة أبعاد وحجم الناتج قبل التنزيل ولا تُعدّل الأصل.
- فحص التكرارات يستخدم SHA-256 لمطابقة محتوى الملفات حرفيًا؛ لا يكتشف التشابه البصري. يعتمد قص الحواف على شفافية PNG/WebP، ويتوقف عند حد أمان 40 مليون بكسل. جميع العمليات محلية في المتصفح.
- المرحلة الثامنة منفذة برمجيًا، لكن الاختبارات والبناء والتحقق من الملفات الكبيرة والتنزيلات مؤجلة إلى نهاية التطوير حسب توجيه المستخدم.
